# ==============================================================================
# Comprehensive User String & Escape Character Test Suite
# Target Commands: addstory, editstory
#
# Specification Tested:
# 1. Escape character:
#    - Backslash (\) escapes the next character if it is a forward slash (/).
#    - An escape character used this way will not be part of the user string.
#    - Otherwise, the escape character is treated as a normal character.
# 2. User string:
#    - Valid user string consists of 1+ characters and cannot start with space.
#    - Any forward slash must be escaped (\/).
#    - Any trailing spaces at the end of user strings are truncated.
#    - Internal spaces are preserved.
#    - Official examples: wumpus, wumpus farts, birthday 3\/12.
# ==============================================================================
