# ==============================================================================
# Comprehensive Active Filter Persistence & Reset Test Suite
#
# Tests the following behaviors:
# 1. After each edit/add/delete/assign/unassign command, the active filters for each
#    panel are not removed. Instead, they are updated to reflect any changes in the
#    underlying domain object.
# 2. Both find-type (keyword) and list-type (linked) filter commands are tested.
# 3. Situations where multiple panels have active filters simultaneously:
#    - All panels active with linked filters
#    - All panels active with find-type filters
#    - Multiple panels active with a mix of linked and find-type filters
# 4. Exception rule: when the domain object used in an active filter is deleted,
#    that filter is reset to the ListAllPredicate. Deleting unrelated entities or
#    entities matching find-type filters does NOT reset the active filters.
# ==============================================================================

# ------------------------------------------------------------------------------
